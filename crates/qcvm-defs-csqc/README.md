# `qcvm-defs-csqc`

Definitions for client-side QuakeC (CSQC, `csprogs.dat`) for `qcvm`, as supported by FTEQW,
DarkPlaces and QuakeSpasm-Spiked.

Only "simple CSQC" `csprogs.dat`s are supported for now: those compiled against the vanilla
Quake 1 system defs (CRC 5927), as QuakeSpasm-Spiked uses for both SSQC and CSQC. The builtins
are the core set that both FTEQW and QuakeSpasm-Spiked support in CSQC.
